# meal-bot

Бот заказа питания (MAX) на Python: роутеры, SQLite, импорт студентов из Excel, уведомления.

## Структура
- `run.py` — точка входа
- `bot/` — маршруты (user, staff, admin), клавиатуры, FSM
- `core/` — БД, сервисы, Excel-импорт, права на обед и выдача
- `config.py` — настройки из переменных окружения
- `data/init_db.py` — инициализация схемы БД

## Установка
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните MAX_BOT_TOKEN
```

## Запуск
```bash
python data/init_db.py   # создать БД
python run.py
```

> `.env` не коммитится (см. `.gitignore`). Реальные токены не должны попадать в репозиторий.

## Схема выдачи питания (кнопка студента + подтверждение сотрудником)
1. Сотрудник нажимает «▶️ Начать выдачу» — до конца суток (по `BOT_TZ`) запросы приходят ему.
2. Студент нажимает «🍽 Получить обед», затем «Подтвердить» — права резервируются, сотруднику приходит
   «Успешно! Иванов И., 28-143. Обедов к выдаче: N».
3. Сотрудник нажимает «Подтвердить» — только после этого выдача пишется в `meals_log`.
   Без подтверждения права возвращаются студенту через `MEAL_CONFIRM_TIMEOUT_MIN` минут.
4. На сутки у студента одно право; «🎁 Угостить друга» создаёт одноразовую ссылку-подарок
   (сумма прав за сутки не растёт, подарки видны на листе «Подарки» в Excel-отчёте).

Код: `core/meals.py` (права, запросы, подарки), `bot/routers/meal.py` (сценарий в чате).
QR-кодов в боте больше нет. Параметры — в `.env.example`.

## Сброс на новый день (для тестов)
`python new_day.py` — выдаёт всем активным студентам право на обед, отменяет подарки и неподтверждённые
запросы сегодняшнего дня, сбрасывает смену выдачи (перед этим делает копию БД в `backups/`).
`--wipe-meals` дополнительно удаляет сегодняшние выдачи, `--yes` — без подтверждения, `--db` — другая БД.
